# Productivity-116

A personal productivity journey tracker built with React and Vite. It helps users turn long-term goals into daily commitments and visualize their progress through a journey spiral.

## Features

- Custom primary goals and journey dates
- Custom daily commitments
- Visual journey progress spiral
- Daily commitment tracking
- Focus timer
- Hydration tracking
- Daily timeline and planning
- Journey progress and milestones
- Dark, Light, and System themes
- Local data persistence
- Data migration and recovery support

## Tech Stack

- React
- Vite
- JavaScript
- CSS
- Lucide React
- localStorage
- Vercel

## Getting Started

### 1. Clone the repository

```bash
git clone <your-repository-url>
cd productivity-116
```

### 2. Install dependencies
```bash
npm install
```
### 3. Start the development server
```bash
npm run dev
```
#### Open the local URL shown in the terminal.

### 4. Build
Create a production build
```bash
npm run build
```
### 5. Lint
Check the project for linting issues
```bash
npm run lint
```
### 6. Preview Production Build
```bash
npm run preview
```
#### Deployment
The project is deployed using Vercel. Vercel automatically installs dependencies and runs the production build when the repository is deployed.
#### Data
Productivity-116 currently uses browser localStorage for storing journey configuration, commitments, focus sessions, hydration, planning, timeline data, theme preferences, and related application state.
